# Code of Conduct

AgentTape contributors are expected to keep project spaces respectful, constructive, and safe.

- Be considerate and focus criticism on ideas and code.
- Welcome people of different backgrounds and experience levels.
- Do not harass, threaten, discriminate against, or expose private information about others.
- Respect maintainers' decisions about scope, safety, and project boundaries.

Report unacceptable behavior privately through the repository owner's GitHub profile. Maintainers may edit or remove contributions and restrict participation when necessary to protect the community.
